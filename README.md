# Collaborative Kanban Board

Minimal vanilla JS scaffold based on `PRD.md`.

## Structure

- `index.html` - app shell
- `css/styles.css` - global styling
- `js/` - feature modules for auth, rooms, tasks, statuses, permissions, realtime, and UI helpers

## Notes

- Firebase files are placeholders for MVP development.
- Identity is loaded from `data/storage.json` instead of `localStorage`.
